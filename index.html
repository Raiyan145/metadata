FAQ

Questions, answered

Every result includes categories mapped to Adobe Stock, Shutterstock, and Freepik's real taxonomies, plus a general category, subcategory, and a recommendation for which marketplace to prioritize. It also works fine for iStock, Dreamstime, and Alamy — you'll just map the general category yourself.

JPG, PNG, and WEBP, up to 10 images per batch. Each image is automatically resized in your browser before it's sent for analysis, so even large camera originals upload quickly.

No. This app has no database. Each image is sent directly to Google's Gemini API for analysis and the result is returned to your browser — nothing is saved on the server in between. Google's own handling of API requests is governed by their Gemini API terms.

Every field is AI-generated and should be reviewed before you submit it to a marketplace. The AI confidence, SEO, and keyword quality scores are there to flag results worth a closer look before you export.

Yes. Each image has its own retry option, so a failed or unconvincing result can be re-analyzed on its own without re-running the whole batch.

Hosting on Vercel's free tier is normally enough for personal use. The Gemini API is billed separately by Google based on usage — check current rates on their pricing page before running large batches.

Yes — the model name is a single constant at the top of api/analyze.js. Change it and redeploy; the rest of the request format stays the same.
